# 🎓 نظام إدارة الطلاب (Student Management System - Single Page)

نظام ويب متكامل لإدارة بيانات الطلاب في صفحة واحدة (SPA - Single Page Application) باستخدام HTML, CSS, JavaScript والتخزين المحلي للمتصفح (LocalStorage).

---

## 📋 نظرة عامة

نظام إدارة الطلاب هو تطبيق ويب متكامل في صفحة واحدة يوفر واجهة سهلة الاستخدام للقيام بالعمليات الأساسية على بيانات الطلاب:

- ✅ إضافة طلاب جدد مع تفاصيلهم (ID، الاسم، القسم، المستوى، المعدل).
- ✅ عرض قائمة بجميع الطلاب المسجلين في جدول منظم.
- ✅ حذف طالب باستخدام رقمه المعرف (ID).
- ✅ لوحة تحكم رئيسية تعرض عدد الطلاب الكلي.
- ✅ نظام مصادقة بسيط للدخول إلى النظام.

---

## ✨ الميزات الرئيسية

- 🔐 **نظام مصادقة**: تسجيل دخول بحساب افتراضي (`username: admin`, `password: 1234`).
- 📱 **صفحة واحدة (SPA)**: جميع العمليات في ملف HTML واحد مع انتقال سلس بين الأقسام.
- 🎨 **واجهة جذابة**: تصميم عصري بألوان داكنة مع تباين جميل (أزرق غامق مع أحمر قرمزي).
- ➕ **إضافة طالب**: إدخال بيانات الطالب مع التحقق من عدم تكرار الرقم المعرف (ID).
- 📋 **عرض جميع الطلاب**: جدول يعرض كامل بيانات الطلاب المسجلين.
- 🗑️ **حذف طالب**: حذف سجل الطالب باستخدام رقمه المعرف.
- 🔄 **تحديث فوري**: يتم تحديث عدد الطلاب تلقائياً عند الإضافة أو الحذف.
- 💾 **تخزين محلي**: استخدام LocalStorage لحفظ البيانات بشكل دائم في المتصفح.
- 🛡️ **حماية الصفحات**: إخفاء أزرار التنقل ووظائف النظام قبل تسجيل الدخول.

---

## 📖 دليل الاستخدام

### 1️⃣ تسجيل الدخول

1. افتح ملف `Student-management-system.html` في المتصفح.
2. ستظهر لك صفحة تسجيل الدخول.
3. أدخل بيانات الدخول:
   - **Username**: `admin`
   - **Password**: `1234`
4. انقر على زر **"دخول"**.

### 2️⃣ الصفحة الرئيسية (Home)

- تعرض **عدد الطلاب** المسجلين في النظام.
- تظهر أزرار التنقل في الأعلى للانتقال بين الصفحات.

### 3️⃣ إضافة طالب (Add)

1. انقر على زر **"➕ إضافة"** في شريط التنقل.
2. املأ جميع الحقول:
   - **رقم الطالب (ID)**: يجب أن يكون فريداً.
   - **الاسم الكامل**.
   - **القسم**.
   - **المستوى** (رقم من 1 إلى 4).
   - **المعدل** (رقم من 0 إلى 4).
3. انقر على زر **"💾 حفظ الطالب"**.
4. ستظهر بطاقة تأكيد بإضافة الطالب مع جميع بياناته.

### 4️⃣ عرض جميع الطلاب (View)

- انقر على زر **"📋 عرض"** في شريط التنقل.
- ستظهر قائمة بجميع الطلاب المسجلين في جدول يحتوي على: ID، الاسم، القسم، المستوى، المعدل.
- إذا لم يكن هناك طلاب، ستظهر رسالة "📭 لا يوجد طلاب حالياً".

### 5️⃣ حذف طالب (Delete)

1. انقر على زر **"🗑️ حذف"** في شريط التنقل.
2. أدخل **رقم الطالب (ID)** الذي ترغب في حذفه.
3. انقر على زر **"حذف"**.
4. ستظهر رسالة:
   - ✅ **"تم حذف الطالب بنجاح"** إذا تم العثور على الرقم.
   - ❌ **"لا يوجد طالب بهذا الرقم"** إذا كان الرقم غير موجود.

### 6️⃣ تسجيل الخروج

- انقر على زر **"🚪 خروج"** في شريط التنقل لتسجيل الخروج والعودة إلى صفحة تسجيل الدخول.

## 🔧 التخصيص والتطوير

### تغيير بيانات تسجيل الدخول

يمكنك تغيير اسم المستخدم وكلمة المرور في دالة `login()` داخل ملف HTML:

javascript
if (username === "admin" && password === "1234") {
    // قم بتغيير admin و 1234 إلى ما تريد
}

## إضافة حقول جديدة للطالب

1. أضف الحقل الجديد في دالة showAdd() داخل النموذج.
2. قم بتعديل دالة addStudent() لجلب القيمة الجديدة.
3. أضف الحقل الجديد إلى كائن student الذي يتم حفظه.
4. قم بتعديل دالة showView() لعرض الحقل الجديد في الجدول.

## تغيير ألوان التصميم

يمكنك تغيير الألوان في قسم <style>:

css
body {
    background-color: darkblue;  /* تغيير لون الخلفية */
}
.logo {
    color: crimson;  /* تغيير لون الشعار */
}


## مسح جميع البيانات

لحذف جميع البيانات المخزنة:

1. افتح أدوات المطور (F12).
2. اذهب إلى Application → Local Storage.
3. انقر بزر الماوس الأيمن واختر "Clear".

## 📝 ملاحظات للمطورين

· جميع البيانات تُخزن في localStorage تحت المفتاح "students".
· حالة تسجيل الدخول تُحفظ في متغير isLoggedIn في الذاكرة فقط (يتم إعادة تعيينها عند تحديث الصفحة).
· هندسة التطبيق: يعمل كـ Single Page Application (SPA) حيث يتم تغيير المحتوى ديناميكياً باستخدام JavaScript.
· أزرار التنقل تظهر فقط بعد تسجيل الدخول الناجح.
· لا يحتاج إلى خادم ويمكن تشغيله مباشرة من المتصفح.
